# Deep Learning Portfolio – CMU 18-786

In **Carnegie Mellon University’s *Introduction to Deep Learning (18-786)* course**, I built everything from the ground up — starting with a **neural network implemented entirely from scratch in NumPy**, and progressing through modern deep learning architectures like **CNNs, GANs, and Transformers**.  

This portfolio captures the breadth and depth of that journey: from low-level backpropagation math → end-to-end implementations → advanced analysis across vision, generative modeling, and NLP.  

---

## 📚 Contents

### **HW2 – Neural Networks From Scratch**
- Built a full **multi-layer perceptron (MLP) from scratch in NumPy** (forward, backward, gradient descent).  
- Implemented multiple optimizers: **SGD, SGD+momentum, Adam**.  
- Compared **L2 vs BCE loss** across tasks.  
- Tackled classic datasets: **linear separable, XOR, circle, sinusoid, swiss roll**, and nonlinear embeddings.  
- **Deliverable:** [📄 HW2_Neural_Networks_From_Scratch.pdf](./HW2_Neural_Networks_From_Scratch.pdf)  
- **Code:** [💻 HW2_code/](./HW2_code/)  

---

### **HW3 – Convolutional Neural Networks (CNNs)**
- Implemented **convolution and pooling layers** from scratch.  
- Trained CNNs and fully connected nets on **CIFAR-100**.  
- Designed a **ResNet-style model** with custom residual blocks.  
- Built a sliding-window style **detector** for object localization.  
- **Deliverable:** [📄 HW3_CNNs_and_Image_Classification.pdf](./HW3_CNNs_and_Image_Classification.pdf)  

---

### **HW4 – Generative Adversarial Networks (GANs)**
- Implemented a **Deep Convolutional GAN (DCGAN)**.  
- Explored **Spectral Norm GAN, WGAN, LS-GAN**.  
- Experimented with training tricks: **label smoothing, top-k training**.  
- Produced generated image samples showing strong convergence.  
- **Deliverable:** [📄 HW4_Generative_Adversarial_Networks.pdf](./HW4_Generative_Adversarial_Networks.pdf)  

---

### **HW5 – Transformers**
- Explored **positional embeddings** (sinusoidal, RoPE).  
- Implemented **corruption pretraining and fine-tuning** pipelines.  
- Compared pretrained vs non-pretrained model performance.  
- **Deliverable:** [📄 HW5_Transformers_and_Pretraining.pdf](./HW5_Transformers_and_Pretraining.pdf)  

---

### **Final Project – Emotion-Aware AI Companion**  
- Designed a **multimodal empathetic AI companion** integrating text sentiment + speech emotion recognition into an LLM-powered agent.  
- Explored CNNs and Vision Transformers for **speech emotion recognition**.  
- Focused on context augmentation to improve **LLM empathy**.
